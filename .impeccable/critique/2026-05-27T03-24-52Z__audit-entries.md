## Anti-Patterns Verdict

**LLM assessment:** Yes, partially AI-slop. Card structure (colored dot → bold name → muted meta → pill pushed right) is the most template-like pattern in modern list UIs. `_ENTRY_ACCENT_PALETTE` imports Tailwind's default accent tones (indigo, violet, fuchsia) against a warm cream canvas. **Banned anti-pattern confirmed:** `border-left: 3px solid` with inline color override.

**Detector:** Overused font (Space Grotesk, false positive — intentional brand typeface); Flat type hierarchy (11–12.5px range, 1.25:1 ratio at minimum threshold — valid).

## Priority Issues

- **[P0]** Side-stripe border: `border-left: 3px solid` with inline color is explicitly banned. Replace with full tinted border.
- **[P1]** `_ENTRY_ACCENT_PALETTE` imports Tailwind cool tones (indigo/violet/fuchsia) that conflict with warm design system. Remove; use only price-tier colors.
- **[P1]** No discrepancy/suspicious-entry visual state. $0 revenue card looks identical to normal entries.
- **[P2]** Price chip is audit noise; third chip in top row interrupts manager read path.
- **[P2]** Dot color uses `_PRICE_ACCENT` flat hex instead of established `_PRICE_COLORS` gradient — breaks learned price-tier color mapping.

## Persona Red Flags

**Maria (Manager):** Indigo/violet/fuchsia cards look broken; $0-revenue discrepancy is invisible. **Carlos (Cashier):** Same price book shows different dot color depending on whether fallback palette fired.
